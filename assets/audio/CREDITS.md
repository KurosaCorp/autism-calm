If a download fails, the script generates a stand-in `.wav` with
`scripts/synth_sounds.py` and lists it in `assets/audio/.standins`. Stand-ins
carry no third-party license. Run the script again later to swap them for the
real recordings.

If you redistribute these audio files (for example in a packaged release),
keep this attribution with them and follow each file's license.
