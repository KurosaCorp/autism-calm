# Example add-on: Breathing circle

A slow breathing guide: a soft glowing circle grows for 4 seconds
("Breathe in") and shrinks for 6 seconds ("Breathe out").

## Install

1. In Autism Calm, open the **Visuals** tab and click **Open add-ons folder**
   (on Windows: `%LOCALAPPDATA%\AutismCalm\Addons`).
2. Copy `breathing_circle.py` into that folder.
3. Restart the app. Choose **Breathing circle** in the picker at the bottom
   left of the Visuals tab.

The Speed slider changes the breathing pace, and Pause stops it.
